## ข้างในโฟลเดอร์เกม

```
<ชื่อเกม>/
├── 00-Index.md         หน้าแรก — อยู่ตรงไหน ทำต่ออะไร ระวังอะไร
├── 01-Story/           📖 เนื้อเรื่อง (เขียนตามหลัง ไม่สปอยล์)
├── 02-Roadmap.md       ลำดับเล่นที่ปลอดภัย
├── 03-Checklists/      ✅ Missables / Collectibles / Bosses / Quests / Achievements
├── 04-Areas/           โน้ตแยกโซน
├── 05-Builds/          บิลด์และอุปกรณ์
├── 06-Sessions/        บันทึกรายวัน
└── 99-Sources.md       แหล่งอ้างอิง
```

## กฎ 3 ข้อของ vault นี้

1. **เปิด `Missables.md` ก่อนขึ้นบทใหม่ทุกครั้ง** — ของที่พลาดคือสิ่งเดียวที่ทำให้ต้องเล่นใหม่
2. **โน้ตเนื้อเรื่องเขียนตามหลัง ไม่เขียนล่วงหน้า** — ไม่สปอยล์ตัวเอง
3. **จบ session แล้วบันทึกทันที** — รอไว้พรุ่งนี้จะจำไม่ได้

## เริ่มเกมใหม่ยังไง

ก๊อป `10-Games/_TEMPLATE-Game/` → เปลี่ยนชื่อเป็นชื่อเกม → แก้ frontmatter ใน `00-Index.md`

หรือบอก Claude ว่า **"เริ่มเกม \<ชื่อเกม\>"** แล้วให้จัดให้
