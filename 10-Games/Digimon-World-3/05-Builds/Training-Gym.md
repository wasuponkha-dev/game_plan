# 🏋️ Training Gym — ฝึกสเตตัสด้วย TP

> ⭐ **ทางแก้เงื่อนไขสเตตัสที่ถูกที่สุด** — ไม่ต้องซื้อ Chip เลย

## กลไก

- ใช้ **TP (Training Points)** ที่สะสมจากการต่อสู้
- เมนูถามว่า **"จะฝึกแบบไหน?"** → เลือกชนิดที่จะฝึก
- **Training Chip 1 / 2 / 3 / V** เพิ่ม TP ได้ 1 / 2 / 3 / 5

## ตัวเลือกที่เห็นในเมนู (7 ช่อง)

| # | ไอคอน | น่าจะเพิ่ม | คำอธิบายในเกม |
|---|---|---|---|
| 1 | 🔥 เปลวไฟ | **Fire** | "ทนความร้อน ตีทนไฟได้เก่งขึ้น" |
| 2 | 🏔️ ภูเขา/ดิน | ? | |
| 3 | ❄️ หมีขาว + เกล็ดหิมะ | **Ice** ⬅ ที่ต้องการ | |
| 4 | 🌀 พัดลม | **Wind** | |
| 5 | ⚡ พืช/สายฟ้า | **Thunder** | |
| 6–7 | ❌ | 🔒 ยังไม่ปลด | อาจปลดที่ยิมระดับสูงกว่า |

> 📝 ให้เลื่อนดูคำอธิบายของแต่ละช่องแล้วมาเติมตารางนี้
