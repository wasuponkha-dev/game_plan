# 📊 สเตตัสแต่ละตัวทำอะไร

| สเตตัส | หน้าที่ |
|---|---|
| **Strength (STR)** | พลังโจมตี**กายภาพ** |
| **Defense (DEF)** | ลดดาเมจ**กายภาพ**ที่ได้รับ |
| **Spirit (SPI)** | พลังโจมตี**เวท** + สเกลดาเมจธาตุ |
| **Wisdom (WIS)** | ⭐ **ความแม่นยำเวท · การหลบ · อัตราคริติคอล · พลังฮีล** |
| **Speed (SPD)** | ลำดับเทิร์น · การหลบ · **โอกาสตี 2 ครั้งติด** |

> 🔧 **แก้ความเข้าใจผิด:** ผมเคยเดาว่า **Wisdom = ป้องกันเวท** — **ผิด**
> Wisdom คือความแม่นยำ/หลบ/คริ/ฮีล
> **ไม่มีสเตตัสป้องกันเวทโดยตรง** → กันเวทได้ทาง **ความต้านทานธาตุ** เท่านั้น

## 🔝 เพดาน 999 — อย่าฝึกเกิน

| เรื่อง | รายละเอียด |
|---|---|
| **Cap** | สเตตัสฐานตันที่ **999** |
| ⚠️ **อย่าฝึกเกิน** | โบนัสจากเลเวลอัปและ TP ส่วนเกิน**เสียเปล่า** |
| **อุปกรณ์ดันเกินได้** | ใส่ของระดับสูงครบชุดดันได้ถึง **~1,009+** |

## 🟣 สเตตัสขึ้นสีม่วง = โดนสาป

ถูกศัตรูสาป (เช่น Cardmon) — **หายเองเมื่อชนะหลายนัด หรือพักที่ Inn**

## 🎯 ลำดับฝึกที่ชุมชนแนะนำ

1. **Speed ก่อน** — หลบได้ + ได้เทิร์นเพิ่ม
2. **บุกก่อนกัน** — สายกายภาพเน้น **Strength** · สายเวทเน้น **Spirit/Wisdom/Speed**
3. **Defense ไว้ท้ายสุด** — เพราะ **เกราะกับโล่ครอบคลุมการป้องกันได้อยู่แล้ว**

> 🔧 **แก้คำแนะนำเดิม:** ผมเคยบอกให้ทุ่ม Defense — **ไม่ใช่ทางที่ดีที่สุด**
> Defense ได้จากอุปกรณ์อยู่แล้ว ส่วน STR/SPD/WIS ต้องฝึกเอา
