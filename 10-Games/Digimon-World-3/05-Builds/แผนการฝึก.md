# 🎯 แผนการฝึกสู่ร่างขั้นสุด

> **สถานะ:** Agumon 27 · Kotemon 23 · Veemon 19 = **เลเวลรวม 69**

---

## 🚨 ขั้นที่ 0 — ไป *รับ* เควส DNA ก่อน (ไม่ต้องทำให้เสร็จ)

> [!tip] ช่วงเลเวลใช้ตอน **รับเควส** เท่านั้น — รับแล้วฟาร์มได้เต็มที่
> เควส DNA ที่ Mobius Desert รับได้เฉพาะช่วง **เลเวลรวม 60–90** → ตอนนี้ 69
> พอรับครบ 3 อันแล้ว แผนฝึกข้างล่างทำได้โดยไม่ต้องกลัวอะไร

- [ ] ไป **Mobius Desert** หาเจ้าหน้าที่ **DRI**
- [ ] รับเควส DNA ให้ครบ **3 อัน** → ได้ Partner เพิ่ม 3 ตัว
- [ ] **รับให้ครบก่อนฟาร์ม** — ไปล้ม Digimon เอา DDNA ทีหลังได้ (ดู [[Key-Items]])

💡 เป้าหมาย DDNA เป็น Digimon ระดับสูง (MetalGreymon · Paildramon · Taomon ฯลฯ) — **ฟาร์มให้แข็งก่อนค่อยไปล้มได้** ขอแค่รับเควสไว้แล้ว

## 🐉 Veemon — เส้นทางที่คุ้มที่สุด (ทำก่อน)

**เป้าหมาย: Imperialdramon** — Veemon ไปถึงถูกกว่าทุกตัวในเกม

**สถานะ:** LV19 · ExVeemon ⚪ ปลดแล้ว · Stingmon 🔵 ยังไม่ปลด

```
ตอนนี้ Veemon LV19
  │
  ├─[1]─ Digivolve เป็น ExVeemon → ปั้นถึง LV30 ──→ ปลด Stingmon
  │
  ├─[2]─ Digivolve เป็น Stingmon → ปั้นถึง LV5
  │
  ├─[3]─ กลับเป็น Veemon → ปั้นถึง LV20 ──→ ปลด Paildramon ⭐
  │
  ├─[4]─ Veemon LV40 ──→ ปลด Imperialdramon
  │
  └─[5]─ Imperialdramon LV99 ──→ Imperialdramon-F
```

| ขั้น | ทำอะไร | ปลดอะไร |
|---|---|---|
| 1 | ExVeemon → **LV30** | Stingmon |
| 2 | Stingmon → **LV5** | (เงื่อนไขของ Paildramon) |
| 3 | Veemon → **LV20** (อีก 1 เลเวล!) | **Paildramon** ⭐ |
| 4 | Veemon → **LV40** | **Imperialdramon** |
| 5 | Imperialdramon → LV99 | Imperialdramon-F |

> 💡 **Veemon เหลืออีกแค่ 1 เลเวลก็ถึง 20** — แต่ Paildramon ต้องมี Stingmon LV5 ด้วย เลยต้องอ้อมไป ExVeemon 30 ก่อน

## 🦖 Agumon — ครึ่งหนึ่งของ Omnimon

**เป้าหมาย: Omnimon** = `WarGreymon 40` + `MetalGarurumon 40` (ต้องมีทั้งคู่ในตัว Agumon เอง)

**สถานะ:** LV27 · Greymon ⚪ · MetalGreymon ⚪ · SkullGreymon 🔵

```
Agumon LV27
  │
  ├─[1]─ Agumon LV40 ──────────→ ปลด WarGreymon
  │
  ├─[2]─ WarGreymon LV10 ──────→ ปลด MetalMamemon
  │      │
  │      └─[3]─ MetalMamemon LV40 ──→ ปลด MetalGarurumon
  │             │
  │             └─[4]─ MetalGarurumon LV40 ─┐
  │                                          ├──→ Omnimon ⭐
  └─[5]─ กลับไปปั้น WarGreymon LV40 ────────┘
```

| ขั้น | ทำอะไร | ปลดอะไร |
|---|---|---|
| 1 | Agumon → **LV40** | WarGreymon |
| 2 | WarGreymon → **LV10** | MetalMamemon |
| 3 | MetalMamemon → **LV40** | MetalGarurumon |
| 4 | MetalGarurumon → **LV40** | (ครึ่งเงื่อนไข Omnimon) |
| 5 | WarGreymon → **LV40** | **Omnimon** ⭐ |

**ทางแยกเสริม (ถ้าอยากได้ BlackWarGreymon)**
- SkullGreymon ← Greymon **LV50** + **Dark 130** → ซื้อ **Devil Chip** (2,800) ดันได้เลย
- BlackWarGreymon ← SkullGreymon LV99

## ⚔️ Kotemon — สายซามูไรประจำตัว

**เป้าหมาย: GuardiAngemon** + เปิดทางสาย Machine

**สถานะ:** LV23 · Dinohumon ⚪ · Greymon ⚪ · Kyukimon 🔵

```
Kotemon LV23
  │
  ├─[1]─ Dinohumon LV50 ──→ ปลด Kyukimon
  │
  ├─[2]─ Kyukimon LV20 ───→ ปลด MetalMamemon (ต้อง Machine 140)
  │      │
  │      └─[3]─ MetalMamemon LV40 + Machine 200 ──→ MetalGarurumon
  │
  └─[4]─ Kyukimon LV99 ───→ GuardiAngemon ⭐
```

| ขั้น | ทำอะไร | ต้องมีอะไรเพิ่ม |

| 3 | MetalMamemon → **LV40** | **Machine 200** → Metal Chip อีก |
| 4 | Kyukimon → **LV99** | → **GuardiAngemon** ⭐ |

> 💡 Kotemon ยังเปิดทางสายเวทได้ด้วย: `GuardiAngemon 20` → **Kyubimon** → Taomon → Sakuyamon

## 🔑 ใช้ Chip ลัดเงื่อนไขสเตตัส

หลายร่างติดที่**สเตตัส** ไม่ใช่เลเวล — ซื้อ Chip กินได้เลย **ไม่ดันเลเวลรวม**

| อยากได้ร่าง | ติดสเตตัสอะไร | ซื้อ Chip | ราคา |
|---|---|---|---|
| Agumon → SkullGreymon | Dark 130 | Devil Chip | 2,800 |
| Agumon → ExVeemon | Ice 320 | Ice Chip | 2,200 |
| Agumon → Kyubimon | Spirit 300 | Mind Chip | 2,400 |
| Kotemon → MetalMamemon | Machine 140 | Metal Chip | 2,600 |
| Kotemon → MetalGarurumon | Machine 200 | Metal Chip | 2,600 |
| Veemon → Greymon | Defense 200 | Armor Chip | 2,000 |
| Veemon → Kyubimon | Ice 200 | Ice Chip | 2,200 |

> ⭐ **นี่คือวิธีคืบหน้าโดยไม่เสี่ยงทะลุเลเวล 90** — ใช้เงินแทนเลเวล

**หาเงินที่ไหน:** ล้ม Digimon ที่ให้ BIT สูง → ดู [[Enemy-Digimon]] (บางตัวให้ 400–1,000 BIT)
**ฟาร์ม Chip ฟรี:** Metal Chip ← Musyamon (AmE: Wind Prairie, Tyranno Valley) · Mind Chip ← Numemon (AmE: Protocol Ruins)
