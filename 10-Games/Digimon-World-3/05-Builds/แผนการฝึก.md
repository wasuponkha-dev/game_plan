# 🦖 Agumon (LV40) — ทางที่สั้นที่สุด

**มีแล้ว:** Greymon · MetalGreymon · **WarGreymon LV99** · Growlmon · **SkullGreymon LV99** · **BK WarGreymon** · MetalMamemon · MetalGarurumon · **🏆 Omnimon**

**เป้าหมาย: เปิดสายมังกร** → ได้ทั้ง Imperialdramon-FM และ GranKuwagamon จากสายเดียว

## ขั้นที่ 0 — ซื้อของ (ทำก่อนเลย)

| ซื้อ | ดันอะไร | ปลดอะไร |
|---|---|---|
| **Ice Chip** ×1–2 | Ice **74 → 100** (ขาด 26) | **Ex-Veemon** · ⚠️ ต้อง**ซื้อ** — Frigimon ที่ดรอปอยู่ North Sector ซึ่งยังไปไม่ได้ |
| **Intelli Chip** ×1 | Wisdom **294 → 300** (ขาด 6) | Angemon (ต้องมี Kabuterimon 20 ด้วย) |

## ขั้นตอน

```
[1] Ice Chip ──→ ✅ Ex-Veemon ──LV5──┐
                                      ├──→ Paildramon ──LV50──→ Imperialdramon
[2] Stingmon (พร้อมแล้ว) ──LV5───────┘                              │
                                                                     ├──LV99──→ Imperialdramon-FM ──LV40──┐
[3] Stingmon ──LV50──→ Kabuterimon ──LV40──┐                        │                                     │
                                            ├──→ GranKuwagamon      │                    ✅ Omnimon ──LV40─┤
[4]              Imperialdramon ──LV40─────┘         │               │                                     │
                                                      └──LV99──┐     │                    👑 Imperialdramon-PM
                                     ✅ BK WarGreymon ──LV99───┴──→ 👑 Diaboromon
```

| ลำดับ | ทำอะไร | ได้อะไร |
|---|---|---|
| 1 | ซื้อ **Ice Chip** → Digivolve **Ex-Veemon** → LV5 | — |
| 2 | Digivolve **Stingmon** (พร้อมแล้ว) → LV5 | **Paildramon** |
| 3 | **Stingmon → LV50** | **Kabuterimon** |
| 4 | **Paildramon → LV50** | **Imperialdramon** |
| 5 | **Imperialdramon → LV40** · **Kabuterimon → LV40** | **GranKuwagamon** |
| 6 | **GranKuwagamon → LV99** · **BK WarGreymon → LV99** | 👑 **Diaboromon** |
| 7 | **Imperialdramon → LV99** → Imperialdramon-FM → **LV40** · **Omnimon → LV40** | 👑 **Imperialdramon-PM** |

# 🐉 Veemon (LV62) — สเตตัสผ่านหมด เหลือแค่ปั้น

**มีแล้ว:** Ex-Veemon · Stingmon · Kabuterimon · Paildramon · MetalMamemon · Devimon · Myotismon · **Imperialdramon** · **Imperialdramon-FM** · **GranKuwagamon**

**เป้าหมาย: ไล่สาย Greymon + Machine** → ได้ BK WarGreymon และ Omnimon

> ✅ **ไม่ต้องซื้อ Chip อะไรเลย** — เงื่อนไขสเตตัสผ่านครบทุกข้อ (Dark 266 · Defense 375 · Machine 168 · Ice 246 · Fire 111 · Wisdom 426)

## 🔑 Paildramon คือรากของทุกสาย

| Paildramon ถึง LV | ปลดอะไร |
|---|---|
| 20 ✅ | MetalMamemon |
| 25 ✅ | Devimon |
| **30** | **Growlmon** → สายอัศวิน |
| **35** | **Greymon** ⬅ ทางไป BK WarGreymon |
| **40** | **Kyubimon** → สายเวท |
| **45** | **Angemon** → สายเทวดา |
| 50 ✅ | Imperialdramon |

👉 **ปั้น Paildramon ให้ถึง 45 รวดเดียว = ปลด 4 สายพร้อมกัน**

## ขั้นตอน

```
[1] Paildramon ──LV45──┬──30──→ Growlmon
                       ├──35──→ Greymon ──LV40──→ MetalGreymon ──LV99──→ WarGreymon ──LV40──┐
                       │           └──LV50──→ SkullGreymon ──LV99──→ BK WarGreymon          │
                       ├──40──→ Kyubimon                                  │                 ├──→ 🏆 Omnimon
                       └──45──→ Angemon                                   │                 │
                                                                          │   MetalMamemon ──LV40──→ MetalGarurumon ──LV40──┘
                                            ✅ GranKuwagamon ──LV99───────┴──→ 👑 Diaboromon
                                                                                        │
                                            ✅ Imperialdramon-FM ──LV40──┬──→ 👑 Imperialdramon-PM
                                                          🏆 Omnimon ──LV40──┘
```

| ลำดับ | ทำอะไร | ได้อะไร |
|---|---|---|
| 1 | **Paildramon → LV45** | Growlmon · **Greymon** · Kyubimon · Angemon |
| 2 | **Greymon → LV50** | MetalGreymon (ที่ 40) + **SkullGreymon** (ที่ 50) |
| 3 | **SkullGreymon → LV99** | **BK WarGreymon** |
| 4 | **BK WarGreymon → LV99** · **GranKuwagamon → LV99** | 👑 **Diaboromon** |
| 5 | **MetalMamemon → LV40** → MetalGarurumon → **LV40** | ครึ่ง Omnimon |
| 6 | **MetalGreymon → LV99** → WarGreymon → **LV40** | 🏆 **Omnimon** |
| 7 | **Omnimon → LV40** + **Imperialdramon-FM → LV40** | 👑 **Imperialdramon-PM** |

## 💥 ท่า DNA พลัง 999

**ไม่ต้องรอปั้นถึง Diaboromon จริง** — ใช้ได้เลยวันนี้

| ท่า DNA อื่นที่ทำได้ | ต้องมี | พลัง |
|---|---|---|
| **Omnimon** | Agumon มี WarGreymon + MetalGarurumon | 850 |
| **Paildramon** | Ex-Veemon + Stingmon | 500 |
