# 🔧 เครื่องมือ

## Obsidian plugin ที่แนะนำ

| Plugin | ใช้ทำอะไร | จำเป็นไหม |
|---|---|---|
| **Dataview** | ทำตาราง Dashboard อัตโนมัติจาก frontmatter | ⭐ จำเป็น |
| **Templater** | กด hotkey แล้วได้โครงโน้ตพร้อมวันที่ | ⭐ แนะนำ |
| **Checklist** | รวม checkbox ที่ยังไม่ติ๊กจากทั้ง vault | แนะนำ |
| **Kanban** | ทำบอร์ดคิวเกม | ถ้าชอบ |
| **Image Toolkit** | ซูมภาพแผนที่ในโน้ต | ถ้าเก็บภาพแผนที่ |
