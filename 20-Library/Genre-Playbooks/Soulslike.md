# 🗡️ Playbook: เกมแนว Soulslike

> ใช้กับ Dark Souls, Elden Ring, Lies of P, Nioh, Sekiro ฯลฯ

## จุดที่มักพลาดในแนวนี้

- **สายเควส NPC** — NPC ย้ายที่ตามความคืบหน้าเนื้อเรื่อง ไม่คุยตอนนั้น = หายถาวร
- **ตีบอสเร็วเกินไป** — บอสบางตัวปิดสายเควสทั้งสาย
- **ไอเทมจากบอสที่มีทางเลือก** — ให้ NPC หรือใช้เอง เลือกได้อย่างเดียว
- **Lore ในคำบรรยายไอเทม** — ต้องอ่านทุกชิ้น ไม่งั้นเนื้อเรื่องไม่ครบ

## ลำดับที่ปลอดภัย

1. เข้าโซนใหม่ → กวาดให้ครบ **ก่อน** ตีบอสโซนนั้น
2. หลังตีบอสทุกตัว → กลับไปคุย NPC ทุกตัวที่ฐาน
3. ก่อนขึ้นบทใหญ่ → เช็ค Missables + เซฟแยก (ถ้าเกมให้เซฟแยกได้)

## สิ่งที่ต้องเก็บใน 1 รอบ

| หมวด | หมายเหตุ |
|---|---|
| อาวุธทุกชิ้น | บางชิ้นต้องแลกจากบอส — เล่นรอบเดียวได้ไม่ครบ |
| เวท/สกิลทุกอัน | |
| ท่า gesture | มักผูกกับ NPC |
| ตอนจบทุกแบบ | ใช้ NG+ หรือเซฟคลาวด์ |

## จำนวนรอบที่ต้องเล่น

ส่วนใหญ่ **2-3 รอบ** (NG+) เพราะไอเทมแลกจากบอสซ้ำกันไม่ได้
